# RetinaFace detection model

- File: `retinaface_mv1_0.25.onnx`
- Architecture: RetinaFace with MobileNetV1 0.25 backbone.
- Source: https://github.com/yakhyo/retinaface-pytorch/releases/tag/v0.0.1
- Source repository license: MIT.
- Runtime: ONNX Runtime CPU, one intra-op and one inter-op thread.
- Purpose: M2 face/portrait detection only; this is not an IDSentinel classifier checkpoint.
