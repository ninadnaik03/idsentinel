# IDSentinel

Independent implementation based on the published methodology in:

Marko Peterlin and Borut Batagelj, "Multi-Branch Forensic Architecture for ID Card Presentation Attack Detection with Portrait Extraction," ERK 2025.

This repository is currently at **Milestone 0 (paper audit and dataset feasibility)**. No model, training pipeline, experiment result, or performance claim has been created yet.

See:

- `docs/PAPER_SPEC.md`
- `docs/DATASET_PLAN.md`
- `docs/IMPLEMENTATION_ASSUMPTIONS.md`
- `docs/IMPLEMENTATION_PLAN.md`

## Research-honesty boundary

The paper's Track 1 dataset is private. Any later results in this repository will be described as an independent implementation evaluated on accessible identity-document PAD data, not as an official reproduction and not as a reproduction of the paper's reported numbers.
